Oh! dsh 编辑团队 · 约 5 分钟读完

这一周 DeepSeek 一口气做了两件事：把第一个 agent 运行时 Harness 开源了，同时把 V4 API 改成错峰计价。一手放、一手收。只要你在 DSH 上开发——或者只是盯着这个方向——这两件事都值得看懂，因为它们说明了 DeepSeek 接下来往哪走。

头条：Harness 开源了

8 月 13 日深夜，DeepSeek 把 Harness（dsh） 放上了 GitHub，MIT 协议，v0.1 开发者预览版。整个理念就一句话：一切皆插件。模型、工具、Agent 主循环、记忆、上下文——每一个都是可替换的组件。

上线几小时 Stars 破 3.3 万，12 小时左右过 5 万。大家都爱叫它「Agent 界的 Android」，我们觉得这个类比只对了一半：Android 是操作系统，而 Harness 更进一步，把「操作系统」本身也拆成了一堆可替换的零件。

技术底座是 Cordis，一个强调「可观察、可组合、可回滚」的元框架。可回滚这一点我们越想越有意思——一个能回退的 Agent，你才敢真的让它去改写自己。

涨价这件事，值得单独说

17 号起，V4 不再统一计费，改成错峰分级：高峰时段最贵，闲时半价。部分档位较原价最高涨了约 11 倍，所以「AI 告别白菜价」这种说法这次不算夸张。

对我们这种天天调 API 的人来说，这是本周最实际的一条。错峰调度从「省钱技巧」变成「硬需求」——如果你的任务能排队，就把它挪到闲时跑。

我们的看法

把开源单纯读成公关动作——「涨价之后火速免费」——就浅了。模型、工具、循环全是插件，意味着开发者可以随便换模型。DeepSeek 赌的是生态绑定，不是模型绑定。

不过预览版就是预览版，澎湃那句「能干活，但得盯着」是实话。完成度、稳定性、文档都还在早期。我们的建议：先拿来玩、把插件化思路吃透，别急着上生产。

至于涨价：错峰定价会把算力往闲时挤。如果你的工作流对延迟不敏感，把任务改到闲时跑——省钱是真的，而且这是今天就能动手做的事。
