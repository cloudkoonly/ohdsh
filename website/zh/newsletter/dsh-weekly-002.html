Harness 迎来第一次安全危机

一个极危 RCE、一个多模态版本、一次调度层布局、一个更便宜的周末——Harness 从「爆火」走进了「成长痛」的这一周。

Oh! dsh 编辑团队 · 约 5 分钟读完

上线一周，DeepSeek Harness 迎来了第一次真正的考验——不是对手，而是一个极危安全漏洞。这其实是个「反向的好信号」：说明装它的人已经多到安全研究者都来了。但也意味着蜜月期结束了，讨论的重心从「有多快」转向「有多稳」。

头条：极危 RCE，CVSS 9.8

8 月 24 日前后，安全研究者披露了 DeepSeek Harness 的一个未授权远程代码执行（RCE）漏洞，评分 CVSS 9.8（极危）。在「人人跟风一夜装机」的热度背景下，这是 Harness 第一次真正意义上的安全危机。

利用细节这里不展开。实操结论很直接：如果你只是跟风装的，先别急着上生产；等官方补丁，并把版本钉在打过补丁的那个上。「能干活，但得盯着」这句话，已经从功能版延伸到了安全版。

这一周，按时间捋

08-17

rc.7 发布：插件设置卡片、PTC mode，以及 DeepSeek 模型的 `low` 推理强度。

08-19

rc.8 落地：14 项更新、原生图片输入，「一周三更」节奏成型。

08-21

V4-Flash-Vision-Exp 上线：Flash 价的多模态视觉，图片最多 384 tokens。

08-23

峰谷计费调整：周末全天按低谷价计费。

08-24

极危 RCE（CVSS 9.8）被披露；Codex Harness 正式开源。

三条值得跟的线

速度。 rc.8 的原生图片输入是头条功能——agent 终于能「看」截图、图表、文档了。但更深的信号是节奏：一周三更意味着势头是真的，对插件作者也是移动靶（我们写过 rc.7 的 keyed 槽位迁移）。

定位。 Harness 把 Claude Code 和 Codex 收编成子代理——明摆着要做所有 Agent 之上的「调度层」，而不是任何一个的对手。

生态。 星标冲过 15 万、企查查等企业数据方开始适配、Codex Harness 开源——「安卓 vs iOS」的对照又多了个注脚。

我们的看法

RCE 是 Harness 必须过的一道门。爆火意味着装机量，装机量意味着安全研究者的关注——这是生态成熟的必经之路，但成熟之前先得把这一下挨过去。我们的态度没变：先拿来玩、吃透插件化思路，生产环境等补丁到位、版本钉死。

节奏上，「一周三更」是双刃剑：势头是真的，变化也是真的。插件作者别把「昨天能跑」当部署策略。

一句话：Harness 已经从「发布事件」进入了「运转阶段」——现在要问的不再是它够不够快，而是它够不够稳。
