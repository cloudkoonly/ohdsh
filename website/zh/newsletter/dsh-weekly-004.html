头条：GPT-6 Astra，与那两句「AGI 宣言」

OpenAI 发布了 GPT-6 Astra，号称「目前智能水平最高的模型」，声浪迅速升级：OpenAI 总裁说「AGI 时代已经到来」，黄仁勋也跟着喊「AGI 来了」，韩国高考满分的成绩成了流传最广的注脚。高盛说这就是 AI 牛市一直在等的那一下；还有人说这是「AI 的 iPhone 时刻」。

同一个星期，反面声音来自 OpenAI 内部：首席科学家警告——「我们正在造出一个没人理解的外星大脑，而且谁都没准备好。」这就是这周最值得盯的分裂：市场部说「到了」，研究负责人说「我们手里还握着个解释不清的东西」。两句话可以同时为真，而它们之间的张力，才是这轮模型周期的真正故事。

DSH 这周：0.1.2 收线，0.1.3 起头

09-03

v0.1.2-rc.1 —— 0.1.2 系列的第一个候选版本，把数周的 alpha 收拢在一起：实验性的 Inspector 工具、实验性的 Web Preview、带自动重试的连接状态显示、父子 Agent 双向 send_message、子代理模型选择。发布说明还专门推荐了 oh-my-dsh 社区的 dsh-plugin-upgrade-skill——帮插件作者跟上这个发版节奏的工具。

09-04

v0.1.3-alpha.1 —— Web 支持上传任意类型文件（文件与图片共用预览区）、出站请求全面支持 HTTP_PROXY/NO_PROXY、Python SDK 新增 macOS x64 wheel，read_image 结果在 Web 工具卡里直接渲染图片。

真正重要的部分：三条破坏性变更

新功能都挺好。但破坏性变更才是这周 DSH 的正片，一共三条：

  • 会话格式升级 v2。 旧的 v0/v1 日志通过不可变的相邻代际迁移到新格式——格式升级的正确姿势，也再次提醒：升级前先备份。
  • 新的 SessionHandle API。 agentLoop.create() 改为异步，新增会话锁，同一个 session 至多被一个进程持有。插件和 SDK 作者都会碰到这条。
  • SQLite 后端没了。 可选的 SQLite 持久化后端被整体移除——已有数据不会删除，但要导出得用旧版本。几周前我们写过 SQLite 存储格式不兼容的提醒，这周就是那篇的下集。

官方还主动标注了 0.1.3-alpha.1 的已知性能回退（影响部分历史会话加载，下个版本修复）。又一句实话——这种坦诚正在成为这个项目的惯例，值得记一笔。

我们的看法

GPT-6 Astra 是能力头条；Harness 这周是地基头条，而耐久的教训都在地基里。在一个 alpha 里打破会话格式、删掉存储后端，正是年轻基础设施该有的动法——趁早、大声、留好迁移路径。Harness 一直在用「相邻代际迁移」「用旧版本导出」这种正确姿势的诚实，做到这一点。

OpenAI 的分裂才是这周真正的张力：同一家公司、同一周，「AGI 时代已到」和「我们在造一个没人理解的大脑」都出自它自己。两句都信，然后校准——更强的模型不会让安全问题变小，只会让它更响。

本周实操就一句话：升级 DSH 前先备份（格式 v2 是单向门）；别让 GPT-6 的锣鼓声盖过基本面——模型月月换，运行时在复利。
