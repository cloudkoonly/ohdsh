怎么用这个目录

1. 先搜索筛选

按分类或关键词筛选 —— 每一条都指向公开的 GitHub 项目。

2. 复制安装命令

命令按上游列表生成，实际包名请以各仓库 README 为准。

3. 装之前先看代码

插件会以你的权限运行第三方代码 —— 先读源码再安装。
