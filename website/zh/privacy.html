1. 我们是谁

Oh! dsh（下称「我们」「本站」）是 ohdsh.com——DeepSeek Harness 生态的独立指南，包括精选插件目录、实战指南、中英双语文档、博客与 DSH Weekly 周刊。本站由位于中华人民共和国香港特别行政区的 Oh! dsh 团队运营。就本政策而言，我们是通过本站收集个人资料的资料使用者。

本政策适用于我们通过本站及我们发送的邮件收集的信息，不适用于本站链接的第三方网站（例如 GitHub 或插件作者网站），后者适用各自的隐私政策。

2. 我们收集的信息

我们尽可能少收集信息。本站没有用户账号、没有支付、没有评论区。下表列出我们实际收集的全部内容。

信息 用途 依据 保存时间
你在 DSH Weekly 订阅表单中提交的邮箱地址 发送周刊与相关通知 你的同意 保留至你退订为止；另保留最低限度记录以履行退订请求
你发送到 support@ohdsh.com 的邮件 回复你的请求 回应请求的正当利益 处理完毕所需时间内保留，随后删除
汇总统计（访问页面、来源、设备类型） 了解哪些内容对读者有用 正当利益 仅以汇总形式保留，不含个人标识
托管平台持有的服务器日志（IP、浏览器标识、时间戳） 安全、防滥用与运维 正当利益 / 必要 短期保留（通常不超过 30 天）

本站统计使用我们自建的 Umami 实例。Umami 不使用 Cookie、不建立用户画像、不做跨站跟踪，只记录汇总的页面访问统计。我们不会通过 Umami 收集 IP 地址，也不会对访问者做指纹识别。

我们不出售个人资料，不基于个人资料投放定向广告，也不收集特殊类别的个人资料。

3. Cookie 及同类技术

本站目前不使用任何广告或营销 Cookie，统计也不使用 Cookie。唯一可能设置的 Cookie 是托管平台用于会话管理与安全的必要 Cookie。详情见Cookie 政策。若未来引入非必要 Cookie（例如开启广告），我们会先更新 Cookie 政策，并在需要取得同意的法域获得同意后再设置。

4. 信息的使用方式与法律依据

  • 周刊。我们只将你的邮箱用于发送 DSH Weekly 与少量相关通知。你可随时通过每封邮件中的退订链接退订。处理基于你的同意，你随时可以撤回。
  • 往来邮件。我们使用你发送的邮件进行回复并改进网站。该处理基于我们的正当利益，并与你的权利相权衡。
  • 统计与运维。汇总统计与服务器日志帮助我们保障站点安全、了解内容效果。在 GDPR 适用的情况下，法律依据为第 6(1)(f) 条（正当利益）。

5. 第三方服务与跨境传输

服务 角色 处理内容

我们的处理者可能在香港以外存储或处理资料。发生跨境传输时，我们依赖这些供应商维持的合约与安全保障；在 GDPR 适用时，依赖标准合约条款等适当保障。

点击外链（例如 GitHub 或插件仓库）会将你带到适用各自隐私政策的第三方网站，我们不对其做法负责。

6. 保存期限与安全

个人资料的保存不超过第 2 条所列目的所需的时间。订阅者数据在你退订后删除（保留最低限度记录以避免重复添加）。我们对传输启用 TLS 加密，限制可接触个人资料的人员范围，并要求处理者维持适当的技术与组织安全措施。任何传输或存储方式都无法做到绝对安全；我们依据所持有的少量数据采取了与其风险相称的合理保障。

7. 你的权利

依据香港《个人资料（私隐）条例》（PDPO），你有权要求查阅及更正你的个人资料。在 GDPR 适用的情况下，你还可以要求删除、限制处理、数据可携，反对基于正当利益的处理，并随时撤回同意。行使任何权利请发邮件至 support@ohdsh.com，我们会在适用法律规定的时限内回应。你也可以向香港个人资料私隐专员公署投诉；在 GDPR 适用时，可向所在地的监管机构投诉。

8. 未成年人

本站是面向开发者的技术资源，不面向 16 周岁以下（或你所在法域的法定数字同意年龄以下）的未成年人，也不会在知情的情况下收集未成年人的个人资料。如你认为有未成年人向我们提供了个人资料，请联系我们，我们会予以删除。

9. 政策变更与联系方式

我们可能不时更新本政策，页首的「生效日期」即最近修订时间；重大变更会在本页显著提示，并在适当时通过邮件告知周刊订阅者。

对本政策有任何疑问：support@ohdsh.com。
