给你的 agent 一支车队

单主机多节点的本地多 agent 管理器，建在 DeepSeek Harness 之上。默认安装 = manager（总办）+ 主脑（总控）+ 个人（工作区）——一条命令、5 分钟用起来。

curl -fsSL https://raw.githubusercontent.com/litestartup-com/dsh-agent-manager/master/install.sh | bash irm https://raw.githubusercontent.com/litestartup-com/dsh-agent-manager/master/install.ps1 | iex

Linux（容器）· Windows（裸机）—— 一条命令，五分钟用起来

为什么做

一个 agent 简单，一支车队很难

跑一个 DSH agent，没问题。跑好几个——一个主脑、几个工蜂、各占一个工作区——你就突然需要派工、排班、成本记账、备份，还要安全到敢让它整夜自己跑。DeepSeek Harness 给你运行时；Oh! dsh 补上控制面。我们做它是因为自己要用：一个个人可自托管的中台，没有云锁定。

能做什么

DSH 没有随箱附带的那个控制面

主脑派工

全局协调入口做规划、开派工单；执行永远委托给工作区。派工轨迹可点击跳回被派的会话，同类任务自动续接。

多节点车队

一个页面管全部 DSH 节点——起/停/重启/日志/新增节点向导；每个节点独立 DSH_HOME、端口和网关密钥。

定时任务

cron 自动化，连续失败自动停用；主脑日预算熔断只拦派工、不拦人工。

看得懂的记账

峰谷计价（周六周日全天谷价）、每次运行的花费、月度汇总、按工作区分账。

备份恢复

15 分钟自动快照 + 保留策略 + 加密归档，一键恢复。

自更新

备份 → 拉新 → 构建 → 探活，失败自动回滚；可注册开机自启服务。

服务器 → 节点（一个 DSH 进程 + 独立 DSH_HOME）→ 工作区（身份 + git 仓）→ 会话 → 运行

建在 dsh-api-gateway 之上

每一次聊天、派工与计量，都流经 dsh-api-gateway——我们那个给任何客户端开门的开源插件。两者合起来就是完整栈：一扇门、一个控制面、三层全开源。

未来

方向

单机版已经是 v1。未来会向多主机多 agent 节点发展，能力包括：为公司产品提供稳定的 agent 集群能力、为个人提供不间断的多 agent 执行任务的能力、为公司员工提供统一的 agent 管理能力。未发布的功能我们不承诺日期——但这支车队，本来就是要跟着你长大的。
