Frequently Asked Questions

What is DeepSeek Harness?

DeepSeek Harness (DSH) is a Cordis-based agent runtime where every capability — tools, models, sandboxes, persistence — is composed as a plugin. It lets you build modular AI agents from reusable pieces.

What is oh! dsh?

oh! dsh is a third-party, community-maintained ecosystem site for DeepSeek Harness. It provides a curated plugin catalog, best-practice documentation, and a changelog for the ecosystem.

How do I find the best DeepSeek Harness plugins?

Start with the plugin catalog, where plugins are organized by capability with clear descriptions, then follow the quick start guide to install one.

Where can I learn DeepSeek Harness best practices?

The best practices guide covers composition patterns, security hygiene, and publishing workflows distilled from real-world DSH projects.

Is the oh! dsh documentation available in Chinese?

Yes. Documentation is fully bilingual: English at /docs/en/ and Simplified Chinese at /docs/zh/.
