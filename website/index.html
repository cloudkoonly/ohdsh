FAQ

Frequently asked questions

What is DeepSeek Harness?

A Cordis-based agent runtime where every capability — models, tools, sandboxes, UI — is a swappable plugin. It lets you compose AI agents from a rich ecosystem of community-built components.

What is Oh! dsh?

An independent expert guide for DeepSeek Harness. We provide curated plugin reviews, real-world scenario guides, and bilingual documentation to help you make the right choices for your DSH projects.

How do I find the best plugins?

Start with our Editor's Picks — 12 hand-tested plugins our team uses daily. Then browse the full directory of 502+ plugins organized by category.

Is documentation available in Chinese?

Yes — full docs in English and Simplified Chinese.

How is Oh! dsh different from the official plugin market?

The official market is an install directory. Oh! dsh is your decision guide — in-depth reviews, scenario recommendations, comparison articles, and best practices to help you choose the right plugins.
