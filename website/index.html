FAQ

What is DeepSeek Harness?

A Cordis-based agent runtime where every capability — models, tools, sandboxes, UI — is a swappable plugin.

What is Oh! dsh?

An independent plugin marketplace and field guide for DeepSeek Harness: curated plugins, honest reviews, and real-world solutions.

How do I find the best plugins?

Start with the plugin catalog, organized by capability with editorial scores and clear verdicts.

Is documentation available in Chinese?
