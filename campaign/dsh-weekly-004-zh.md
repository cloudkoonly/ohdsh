## GPT-6 Astra 发布，AGI 之争升温

OpenAI 发布 GPT-6 Astra，号称「目前智能水平最高的模型」，总裁宣告「AGI 时代已经到来」，黄仁勋也喊出「AGI 来了」。但同一个星期，OpenAI 首席科学家发出警告：我们正在造一个没人理解的外星大脑，谁都没准备好。

两句话可以同时为真——更强的模型，只会让安全问题更响。

## DeepSeek Harness 重打地基

v0.1.2-rc.1 与 v0.1.3-alpha.1 相继发布：实验性 Inspector 与 Web Preview、任意类型文件上传、HTTP 代理支持、Python SDK macOS 版。更重要的是三条破坏性变更：

- **会话格式升级 v2**（旧日志自动迁移，升级前请先备份）
- **新 SessionHandle API**（同一会话至多被一个进程持有）
- **SQLite 存储后端移除**（导出数据请用旧版本）
