# Plugin Catalog

The Oh! dsh plugin catalog is a curated list of DeepSeek Harness plugins, organized by what they do — not by who wrote them.

## How the catalog works

- **Curated** — every entry is hand-picked and reviewed before listing
- **Capability-first** — plugins are grouped by capability so you can find what you need fast
- **Clear descriptions** — each entry explains what the plugin does, its requirements, and when to use it

## Categories

| Category | Use for |
|----------|---------|
| Tools | Adding new model-facing tools to your agent |
| Services | Sharing capabilities across plugins and sessions |
| UI / Slots | Extending the harness web interface |
| Workflows | Orchestrating multi-step agent work |

## Catalog principles

- Every entry is hand-picked and reviewed before listing
- Plugins are grouped by capability, not by author
- Descriptions state what a plugin does, its requirements, and when to use it
